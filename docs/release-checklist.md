# 「止念」发布工作清单

> 项目：`mind_trace`  
> 目标：微信原生小程序 + Go API + 腾讯云 MySQL + Vue 3 管理端。  
> 用法：按顺序执行，在每项后记录负责人、完成日期和证据链接（控制台截图、工单、测试报告或命令输出）。平台规则与控制台选项可能变化，提交前以微信和腾讯云当期要求为准。

**审核时长不可控，本项目不承诺微信审核、备案或证书申请的具体完成时长；排期必须预留驳回整改和重新提交的时间。**

## 1. 微信主体、账号与凭据

- [ ] 注册/确认微信公众平台的账号类型为**小程序**，不是小游戏、公众号或服务号。
- [ ] 完成主体信息、管理员和所需成员权限配置；开发者、体验成员、运营人员权限最小化。
- [ ] 获取真实 `AppID`；保存在服务端环境变量 `WECHAT_APP_ID` 和微信开发者工具项目配置中。
- [ ] 在公众平台生成/重置 `AppSecret`，仅配置到 Go 服务 `WECHAT_APP_SECRET`。
- [ ] 确认 AppSecret 未进入小程序包、Vue 构建产物、Git、日志、截图或工单正文；泄露时立即轮换。
- [ ] 生产 `AUTH_DEV_MODE=false`；确认 `dev_` 前缀 code 在生产不可用。
- [ ] 开启微信接口调用的超时、失败告警和必要的访问限制；不记录 `session_key`。
- [ ] 本地开发可用 `touristappid`，但真机预览、体验版和正式发布必须使用真实 AppID。
- [ ] 使用 [微信开发者工具 Stable](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 导入 `miniprogram` 目录，确认项目类型为小程序并编译通过。

## 2. 腾讯云与 MySQL

- [ ] 选择腾讯云账号、地域和 VPC；生产数据库与 API 位于可互通的私有网络。
- [ ] 创建腾讯云 MySQL 实例，版本、字符集 `utf8mb4`、时区策略和容量经评审；应用统一存 UTC 时间。
- [ ] 创建独立应用数据库和最小权限账号；禁止 Go 服务使用 root，禁止小程序持有数据库账号。
- [ ] 配置安全组：3306 仅允许 API 实例/子网访问；关闭不必要的公网访问和 `0.0.0.0/0` 入站。
- [ ] 配置 `MYSQL_DSN`，使用秘密管理方式注入；验证连接、TLS（按实例能力）、连接池和超时。
- [ ] 执行数据库迁移，核对 users、thoughts、records 等表、唯一键、级联删除和索引；V1 使用 JWT，不创建 sessions 表。
- [ ] 验证 `(thought_id, version_no)` 与 `(user_id, client_request_id)` 唯一约束、离线重试返回首次结果、并发新增版本不冲突、所有业务查询按 `user_id` 隔离。
- [ ] 检查慢查询日志、磁盘/连接数/CPU 告警和容量阈值。
- [ ] 测试环境不使用生产用户正文；如需数据演练，使用合成数据。

## 3. 域名、ICP备案与 HTTPS

- [ ] 准备 API 域名（如 `api.example.com`）和管理端域名（如 `admin.example.com`），由发布主体可控。
- [ ] 若服务部署在中国内地，按规定完成域名 **ICP备案**，并确保备案主体、小程序主体及实际服务关系符合当期要求。
- [ ] 备案未完成前，不提交依赖该域名的正式版；不要将审核或备案时长写成确定承诺。
- [ ] 配置 DNS 到 Nginx/负载均衡；按当期规定检查公安联网备案等其他要求。
- [ ] 为 API 与管理端申请受信任证书，部署到 443；HTTP 仅用于跳转 HTTPS 或按平台要求关闭。
- [ ] 检查完整证书链、域名匹配、TLS 配置和双向时间同步；配置自动续期及到期告警。
- [ ] Go API 仅通过 HTTPS 对外提供；管理端静态资源无 HTTP 混合内容。
- [ ] 验证 Web、微信小程序真机均能访问，错误页面和日志不泄露 SQL、密钥或用户正文。

## 4. 微信公众平台配置

- [ ] 在“开发管理 → 开发设置 → 服务器域名”中配置 `request` 合法域名为 API 的 HTTPS 域名。
- [ ] 合法域名不带路径，不使用 IP、端口或 `http://`；如使用文件上传/下载，再单独配置对应合法域名。
- [ ] 域名按要求完成校验文件或主体验证；保存后记录控制台配置截图。
- [ ] 开发者工具中不要依赖“不校验合法域名”通过测试；关闭该选项复测，真机再次复测。
- [ ] 配置业务域名/网页域名仅在确有需求时进行，不申请无关能力。
- [ ] 核对小程序名称“止念”、图标、简介、服务范围与实际功能一致，不使用医疗诊断、治疗或疗效承诺等未经支持的表述。

## 5. 隐私协议与敏感个人信息

- [ ] 发布可访问的隐私政策，列明运营主体、联系方式、收集字段、处理目的、方式、范围、保存期限、共享情况、用户权利和注销渠道。
- [ ] 明确列出触发事件、情绪标签、强度、循环念头、风险评估、平衡视角等用户主动填写内容；说明用于登记、评估、检索、统计和多设备同步。
- [ ] 将情绪、心理相关记录按**敏感个人信息**进行保护评估；根据当期法规与平台要求提供单独同意/明示同意流程，并保留必要记录。
- [ ] 在微信公众平台“用户隐私保护指引”中如实声明实际收集的信息和接口；代码、指引、隐私政策三者一致。
- [ ] 首次收集前展示清晰告知；拒绝可选资料（昵称、头像）不影响核心登记功能。
- [ ] 不申请通讯录、位置、麦克风等无关权限；如后续增加语音转文字，先更新评估、隐私声明和平台配置。
- [ ] 验证 `DELETE /me` 删除当前用户全部业务数据，旧 JWT 因用户不存在而失效；客户端同步清除令牌、敏感缓存与离线队列。
- [ ] 说明备份副本的保留与到期清除机制；注销失败不得提示“已删除”。
- [ ] 管理端只显示契约允许的聚合指标和用户元数据，不显示思虑正文。
- [ ] 若产品提供安全求助提示，不将其描述为医疗或紧急救援服务；即时风险应引导联系可信赖的人或当地紧急服务。

## 6. 服务类目与提审材料

- [ ] 在微信公众平台选择与实际功能相符、当前主体可用的小程序服务类目，并提交所需资质。

- [ ] 产品描述准确为思虑登记、结构化评估、检索与统计工具，不夸大疗效，不以类目选择掩盖实际服务。

- [ ] 若审核测试需要专用账号或数据，采用安全、可回收的方式，不在代码中留万能口令。

## 7. Go API 与 Vue 管理端上线

- [ ] `go test ./...`、Go 构建和数据库迁移检查通过；生产二进制/镜像固定版本。
- [ ] `npm run build` 通过；若后续配置测试脚本，再执行对应测试命令。无 sourcemap 泄露秘密或正文。
- [ ] 配置 `APP_ENV=production`、`PORT`、`MYSQL_DSN`、`JWT_SECRET`、`JWT_TTL_HOURS`、`WECHAT_APP_ID`、`WECHAT_APP_SECRET`、`ADMIN_USERNAME`、`ADMIN_PASSWORD`、`ALLOWED_ORIGINS`；JWT 密钥至少 32 字节，管理员密码使用高强度独立值。
- [ ] Nginx 配置 `/api/v1` 反向代理、Vue 静态文件、请求体上限、超时、安全响应头和基础限流。
- [ ] 健康检查不泄露依赖秘密；Go 服务具备优雅退出、崩溃恢复和最小系统权限。
- [ ] `/admin/*` 与用户令牌隔离；管理员账号仅来自环境变量，不在数据库或前端硬编码。
- [ ] 验证成功响应为 `{data}`、失败为 `{error:{code,message}}`，时间使用 RFC3339。
- [ ] 验证越权：用户 A 不能读取/修改用户 B 的思虑点、版本、统计，不能通过传 `userId` 绕过。
- [ ] 验证生产拒绝 `dev_` 登录；AppSecret、DSN、token 和正文均不出现在日志。

## 8. 功能、离线、兼容与安全验收

- [ ] 快速登记字段约束：触发事件 1–100 字、循环念头 1–1000 字、强度 1–10；概率 0–100。
- [ ] 七步草稿可保存/恢复，平衡视角三栏与三项确认未满足时不能收尾。
- [ ] 版本状态仅 `registered / evaluating / paused / closed`；思虑点状态仅 `active / resolved / recurring`。
- [ ] 相似匹配只提示；用户选择后携带 `thoughtId`，新版本继承但不覆盖旧版本。
- [ ] 弱网、断网、切后台、微信被杀进程后，本地草稿和 outbox 不丢；“已存本机”和“云端已同步”文案准确。
- [ ] 超时等结果未知时不盲目自动重放；测试重复点击不会由客户端造成意外重复登记。
- [ ] 应急叫停断网可用，退出后原草稿仍在；不新增接口外状态。
- [ ] 搜索、状态/情绪筛选、分页、空态、错误态、统计与 API 返回一致。
- [ ] 覆盖主流 iOS/Android 微信、不同屏幕、深色/减少动态效果设置及开发者工具 Stable；真机用真实 AppID。
- [ ] 检查令牌存储、接口鉴权、SQL 参数化、请求限流、管理端登录限速和敏感日志。
- [ ] 完成一次注销演练：云端业务数据不可再访问，本地敏感缓存清空，备份处理符合已公布规则。

## 10. 提交审核、发布与回滚

- [ ] 冻结提审代码与配置，生成最终发布单和数据库备份点。
- [ ] 提交微信审核，填写真实完整的功能说明、类目和隐私信息，保存提交编号。
- [ ] **不向用户或团队承诺审核时长**；审核中持续查看站内通知，驳回则按原因修复并重新走必要测试。
- [ ] 审核通过后由授权人员执行发布；确认发布版本、API 版本和数据库迁移相互兼容。
- [ ] 采用可用的灰度/分阶段发布能力；先观察登录、5xx、延迟和核心登记成功率，再扩大范围。
- [ ] 发布后真机 smoke test：登录、登记、同步、评估收尾、思虑库、统计、隐私入口。
- [ ] 出现阻断问题时停止扩大发布；按预案回滚小程序/API/管理端，数据库迁移使用预先验证的兼容或恢复方案。
- [ ] 记录实际发布时间、版本、异常、处置和后续改进，不删除审核或运维证据。

## 11. 监控、备份与持续运营

- [ ] 告警上线并验证接收人：API 存活、5xx、P95 延迟、微信登录失败、DB 连接/慢查询/磁盘、证书到期、备份失败。
- [ ] 日志按请求 ID 关联，但不采集思虑正文、token、AppSecret、session_key、MySQL 密码。
